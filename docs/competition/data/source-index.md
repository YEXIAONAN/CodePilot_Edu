## 五、引用规则

1. 引用官方规则必须写“依据 S0x + 文件名 + 页码/章节”，不得只写“据大赛要求”。
2. 二手转述（如网页摘要、他人整理）不得标注为原件。
3. 同一事实出现冲突时，按 `AGENTS.md` B 节优先级处理，并在 `evidence-ledger.csv` 的 notes 中登记冲突。
4. 新增来源时先在本表登记编号，再在事实库和台账引用。
