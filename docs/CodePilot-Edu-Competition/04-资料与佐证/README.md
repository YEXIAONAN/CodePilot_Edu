# CodePilot Edu 资料与佐证目录

本目录用于保存官方原件、公开资料核查和后续真实证明材料。原件与生成的申报文稿分开保存，不生成学生证、学籍证明、证书、合同、签名或印章。

## 已有资料

- 学校提供RAR原包及解压后的2026年10月21日校通知、附件1学生赛道项目评审书、附件2学生赛道评审规则。申报书以本校原版附件1填写。
- 同届广西区赛桂统字〔2026〕1号盖章通知、区赛原版评审书与规则，作为时长和要求的补充依据。
- 《竞品公开资料核查.md》：5类竞品公开官方功能对照、来源链接及未确认事项。
- 《项目事实与状态清单.md》：区分负责人确认信息、方案成果及尚待补充的研发/经营证据。

本轮未建立空白“证书”或“证明”文件，以免被误当作已有成果。补充时为每条对外主张分配证据编号，记录日期、版本、责任人和原件位置。涉及个人信息的材料仅按竞赛需要提供，不在公开答辩页展示完整证件或联系方式。

PPT中的代码与提示组合是带标识的设计效果图，不能作为真实系统运行证据。正式查重报告与学校签章由有权机构或本人完成，详情见05审核记录中的清单。
